# 신청·문의 연동 명세

## 공통

- 문자 인코딩: UTF-8. 양식 전송: `application/x-www-form-urlencoded`.
- 같은 도메인에서 `POST /registrations`와 `POST /inquiries`를 처리합니다. `html-site/`을 하위 경로에 설치했다면 해당 하위 경로 기준으로 라우트를 연결합니다.
- 브라우저의 `required`, `maxlength`, `pattern`만 믿지 말고 서버에서 모든 항목을 다시 검증합니다. 저장 성공 전에 완료 화면을 표시하지 않습니다.
- HTTPS, 요청 출처 확인, 과도한 반복 제출 제한, 관리자 인증 및 백업이 필요합니다. 숨김 필드 `website`에 값이 있으면 자동 제출로 처리합니다.

## 강의 신청: `POST /registrations`

| 입력 이름 | 내용 | 규칙 |
| --- | --- | --- |
| `lecture_id` | 신청 강의 ID | 공개된 강의 ID와 일치해야 함 |
| `name` | 이름 | 필수, 1~50자 |
| `phone_prefix` | 휴대전화 앞자리 | `010`, `011`, `016`, `017`, `018`, `019` |
| `phone_middle` | 가운데 자리 | 숫자 3~4자리 |
| `phone_last` | 끝자리 | 숫자 4자리 |
| `gender` | 성별 | `여자`, `남자`, `응답하지 않음` |
| `age_range` | 연령대 | 화면에 표시된 선택지 중 하나 |
| `session_preference` | 시간대 | `오전 시간대`, `오후 시간대`, `시간대 무관` |
| `referral_source` | 직접 선택한 유입 경로 | `인스타그램`, `페이스북`, `당근`, `카카오`, `유튜브`, `네이버`, `기타` |
| `consent` | 개인정보 수집·이용 동의 | `yes` 필수 |
| `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term` | 광고 URL에서 전달된 값 | 각 120자 이내, 비어 있어도 됨. 서버에서도 검증·길이 제한 |
| `website` | 스팸 방지용 숨김 입력 | 정상 사용자는 빈 값 |

전화번호는 숫자만 합쳐 저장합니다. 같은 `lecture_id`와 전화번호 조합으로 이미 신청했다면 중복 안내를 반환합니다. 운영 DB에서는 고유 제약을 적용하는 것이 좋습니다. 접수 시간은 서버에서 기록하고 시간대를 일관되게 관리해 주세요.

현재 Node.js 구현은 저장 성공 시 `303`으로 `/lectures/{id}?registered=1#register`로 이동하고, 동일 번호 중복은 `409`로 안내합니다. 정적 HTML을 사용할 때는 `/lectures/{id}/index.html?registered=1#register`로 이동시키면 완료 메시지가 표시됩니다. **실제 DB 저장 후에만** 성공 주소로 이동시켜야 합니다.

## 홈페이지 문의: `POST /inquiries`

| 입력 이름 | 내용 | 규칙 |
| --- | --- | --- |
| `name` | 이름 | 필수, 1~50자 |
| `contact` | 연락처 | 필수, 1~100자 |
| `kind` | 문의 유형 | `강의 일정`, `기업·단체 교육`, `기타 문의` |
| `message` | 문의 내용 | 필수, 1~2000자 |
| `consent` | 개인정보 동의 | `yes` 필수 |
| `website` | 스팸 방지용 숨김 입력 | 정상 사용자는 빈 값 |

저장 성공 후에는 홈페이지 문의 영역으로 이동하고 접수 완료를 보여 주세요. 관리자만 문의 내용을 볼 수 있게 합니다.

## 운영자 기능

- 강의: 공개·비공개, 일정, 지역, 대표 이미지, 긴 랜딩 이미지, 신청 버튼과 강의 ID 연결.
- 후기: 사진, 제목, 내용, 표시 순서, 공개·비공개, 추가·수정·삭제.
- 신청자: 강의별 목록, 중복 상태, 휴대전화번호, 유입 경로, UTM 및 접수 시간 조회. 인증된 관리자에게만 CSV 다운로드 제공.
- 문의: 관리자 조회 및 처리. 개인정보 보유 기간에 맞춘 정기 삭제와 백업 관리.

현재 Node.js 구현의 SQLite 스키마는 `node-app/server.js`의 `CREATE TABLE`과 마이그레이션 코드를 참조할 수 있습니다. 초기 공개 강의·후기는 `html-site/public-content.json` 또는 `node-app/seed/public-content.json`에서 가져올 수 있습니다. 신청자와 문의의 실제 기록은 인계 파일에 포함되지 않습니다.
