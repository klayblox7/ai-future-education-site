# AI 미래교육원 홈페이지

별도 브랜드 홈페이지와 강의 운영 관리자입니다. Node.js 24 이상에서 외부 패키지 없이 실행됩니다.

## 실행

PowerShell에서:

```powershell
$env:ADMIN_PASSWORD = '길고_고유한_관리자_비밀번호'
npm start
```

브라우저에서 `http://localhost:3000`을 열고, `/admin`에서 로그인합니다. 처음 실행할 때는 저장소에 포함된 공개 강의 2건과 해당 이미지를 새 데이터베이스에 자동으로 복사합니다. 이후 수정한 내용은 각 서버의 `DATA_DIR`에 보존됩니다.

로컬 미리보기용 `.env.local` 파일이 있다면 `npm start`가 자동으로 읽습니다. 새 컴퓨터에서는 `.env.example`을 참고하여 **새로운 관리자 비밀번호**를 설정하세요. `.env.local`과 실제 운영 데이터는 Git에 포함되지 않습니다.

## 관리자 사용

1. `강의 추가`에서 제목, 짧은 소개, 상세 본문, 날짜와 장소를 입력하고 저장합니다.
2. 저장 후 수정 화면의 `상세 이미지`에서 사진을 올립니다. 첫 사진이 목록과 상세 페이지의 대표 이미지입니다. JPG, PNG, WebP를 강의당 최대 12장, 파일당 8MB까지 등록할 수 있습니다.
   긴 랜딩페이지 이미지는 `본문 아래 랜딩페이지 이미지`에서 별도로 업로드합니다. 파일당 20MB까지 가능하며, 새로 올리면 기존 이미지가 교체됩니다. 상세 페이지의 소개 글 아래에 원래 비율로 표시됩니다.
3. `홈페이지에 공개`를 체크하면 강의 목록에 나타납니다. 목록에서 강의를 누르면 `/lectures/강의번호` 상세 페이지가 열립니다. 비공개 강의는 상세 주소로도 볼 수 없습니다.
4. 기존 신청 랜딩페이지의 HTTPS 주소는 선택 사항입니다. 입력하면 상세 페이지의 신청 버튼에 연결되고, 비워 두면 문의 양식으로 연결됩니다.
5. 강의의 글과 이미지는 언제든 수정하거나 삭제할 수 있습니다. 같은 주제를 반복 운영한다면 일정을 하나씩 추가합니다. 월별 개수 제한은 없습니다.
6. 강사 정보는 관리자에서 추가하고, 문의는 `문의함`에서 확인합니다.

강사 정보는 아직 등록되지 않았습니다. 첨부된 `11.jpg`는 참고용으로 `public/assets/sample-landing.jpg`에 보관했습니다.

## 배포 및 데이터

강의 글은 `DATA_DIR/site.sqlite`, 업로드한 이미지는 `DATA_DIR/uploads`에 저장됩니다. 서버 재배포 후에도 데이터가 유지되는 **영구 디스크**에 `DATA_DIR`을 연결하고 전체 폴더를 정기 백업하세요. 정적 파일만 제공하는 호스팅에서는 관리자 기능이 작동하지 않습니다. `PUBLIC_ORIGIN`은 실제 사이트의 HTTPS 주소로 설정합니다.

온라인 운영에는 Node.js 24 서버 또는 동봉된 `Dockerfile`, HTTPS 주소, 영구 디스크가 필요합니다. 환경 변수 `ADMIN_PASSWORD`(12자 이상), `PUBLIC_ORIGIN`, `DATA_DIR`을 설정하세요. GitHub 저장소 자체는 서버를 실행하거나 업로드 이미지를 저장하지 않습니다. 여러 관리자가 동시에 사용한다면 현재의 단일 비밀번호 대신 개인별 계정 기능을 추가하는 것이 좋습니다.

공개 강의 자료를 다시 GitHub에 반영하려면 운영 데이터가 있는 컴퓨터에서 `npm run seed:export`를 실행한 뒤 `seed/` 변경분을 커밋하세요. 문의 내역과 관리자 비밀번호는 내보내지 않습니다.

실제 강의 후기가 생기기 전에는 공개 홈페이지에 후기 영역을 표시하지 않습니다. 개인정보처리방침과 서비스 정책은 실제 신청 방식과 위탁 업체에 맞춰 공개 전 검토가 필요합니다.
